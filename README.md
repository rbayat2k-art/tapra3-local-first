# شاهراه — نسخه Local-First

نسخه فعلی شاهراه یک محصول فارسی و راست‌به‌چپ است که برای طراحی، پذیرش و آزمون گردش‌کارها کاملاً در مرورگر اجرا می‌شود. شناسه‌های فنی قدیمی مانند نام package، دیتابیس و snapshot برای سازگاری داده تغییر نکرده‌اند.

## معماری فعلی

```text
رابط کاربری مرورگر
→ لایه کاربرد و گردش‌کار
→ قوانین دامنه و دسترسی
→ StorageAdapter
→ IndexedDBAdapter
→ IndexedDB
```

- بدون PostgreSQL، API Server یا سرویس بک‌اند
- داده عملیاتی فقط در IndexedDB
- localStorage فقط برای تنظیمات ظاهری رابط
- پشتیبانی از نقش، مجوز، محدوده، سیاست رکورد و Audit
- داده آزمایشی قطعی، Reset، Backup و Snapshot Import/Export

## اجرا

نیازمندی: Node.js 22 یا جدیدتر.

```bash
npm ci
npm run dev
```

آدرس پیش‌فرض: `http://localhost:3000`

## کنترل کیفیت

```bash
npm run typecheck
npm test
npm run build
```

## ورود آزمایشی محلی

- نام کاربری: `admin`
- رمز عبور: `Tapra2@123`

این حساب فقط برای Seed آزمایشی نسخه مرورگرمحور است و نباید در محیط عملیاتی واقعی استفاده شود.

## محدوده مخزن

این مخزن Snapshot تمیز نسخه فعلی محصول است. داده‌های IndexedDB مرورگر، فایل‌های موقت، خروجی ساخت، وابستگی‌های نصب‌شده و کد بک‌اند قدیمی در آن قرار نگرفته‌اند.

جزئیات معماری محلی در `docs/architecture/local-foundation.md` ثبت شده است.
