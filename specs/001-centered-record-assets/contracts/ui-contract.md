# UI Contract

## RecordDialog

- در دسکتاپ در مرکز viewport، با فاصله از چهار لبه، `max-height` و یک ناحیه scroll داخلی نمایش داده می‌شود.
- در موبایل حداکثر 640px، تمام‌عرض در پایین viewport و بدون overflow افقی است.
- `role="dialog"`، `aria-modal="true"` و نام قابل‌دسترسی دارد.
- هنگام بازشدن focus داخل پنجره می‌رود؛ Tab و Shift+Tab خارج نمی‌شوند؛ Escape می‌بندد؛ focus به trigger بازمی‌گردد.
- overlayهای portaled مانند تقویم شمسی داخل target همین پنجره قرار می‌گیرند؛ تا هنگام بازبودن در چرخه focus هستند و Escape ابتدا overlay را می‌بندد، نه پنجره اصلی را.
- کلیک داخل content نمی‌بندد؛ backdrop همان رفتار بستن فعلی را حفظ می‌کند.
- header/body/footer و تمام actionهای دامنه موجود بدون تغییر می‌مانند.
- هفت مصرف‌کننده: عمومی ERP، مساعده، خرید، خزانه، اموال، خروج پرسنل و استخدام.

## Operation Error

- خطای سرویس با `role="alert"` و متن واضح بالاتر از scrim و داخل viewport دیده می‌شود.
- دکمه بستن نام قابل‌دسترسی دارد.
- failure پنجره را نمی‌بندد و state فیلدهای کاربر را پاک نمی‌کند.
- validation محلی داخل فرم و نزدیک action مربوط باقی می‌ماند.

## Personnel Assets

- یک تب «دارایی‌ها و اموال» فقط برای پرونده موجود و فقط با مجوز مشاهده هر سه ماژول دارایی، انتقال و نگهداری نمایش داده می‌شود؛ داده هر ماژول جداگانه با Scope/Resource کاربر فیلتر و در حالت خارج از محدوده پنهان می‌شود.
- چهار گروه داده: دارایی جاری، انتقال در انتظار، تاریخچه تحویل/عودت و گزارش مشکل.
- جزئیات و رسید قابل مشاهده است، اما OTP، گزارش خرابی، درخواست عودت یا تغییر متولی در نمای پرونده شخص دیگر وجود ندارد.
- empty state و داده ناقص متن فارسی روشن دارند.
- داده مستقیماً از state فعال و بدون store/migration جدید خوانده می‌شود.
