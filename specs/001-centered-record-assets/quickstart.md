# Quickstart Verification

## بررسی دستی

1. با حساب مدیر وارد شوید و یک رکورد عمومی مانند مرخصی را باز کنید؛ پنجره در دسکتاپ وسط صفحه باشد.
2. نمونه‌های خرید/خزانه، مساعده، اموال، خروج و استخدام را باز کنید؛ محتوا و actionهای قبلی حاضر باشند.
3. با Tab و Shift+Tab حرکت کنید، Escape را بزنید و بازگشت focus به دکمه بازکننده را بررسی کنید.
4. یک validation محلی ایجاد کنید؛ خلاصه خطا داخل فرم باشد.
5. یک خطای سرویس ایجاد کنید؛ alert روی پنجره دیده شود، فرم باز بماند و ورودی حفظ شود.
6. عرض 390px را بررسی کنید؛ پنجره تمام‌عرض پایین و بدون scroll افقی باشد.
7. پرونده یک پرسنل را باز کنید و تب «دارایی‌ها و اموال» را ببینید؛ دکمه‌های self-service نباید حاضر باشند.
8. چاپ خزانه را بررسی کنید؛ chrome پنجره وارد چاپ نشود.

## Gateهای خودکار

```text
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

## معیار توقف

هر شکست gate، تغییر مجوز/داده، regression چاپ، overflow موبایل یا خطای پنهان مانع DONE است.
