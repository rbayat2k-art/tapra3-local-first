# مرکز مستندات Tapra2 Local-first

> **وضعیت:** `Verified` — آخرین تطبیق با شاخه `feature/workflow-management`، commit پایه `853dac0` و تغییرات محلی موجود در ۱۴۰۵/۰۵/۳۱ (2026-08-22).

این پوشه مرجع فعلی محصول مرورگرمحور Tapra2 است. اجرای فعلی به Server، API، PostgreSQL یا سرویس خارجی وابسته نیست؛ داده عملیاتی در IndexedDB و فقط ترجیحات ظاهری در localStorage نگهداری می‌شود.

## معنای برچسب‌های اطمینان

| برچسب | معنا |
|---|---|
| `Verified` | مستقیماً در کد، تست، پیکربندی یا اجرای قابل تکرار تأیید شده است. |
| `Implemented-Unverified` | در کد وجود دارد، اما در این بازبینی اجرا یا تست مستقیم نشده است. |
| `Documented` | در سند یا تصمیم محصول آمده، اما الزاماً در اجرای فعلی تأیید نشده است. |
| `Inferred` | از چند شاهد فنی استنباط شده و باید در بازبینی بعدی تأیید شود. |
| `Planned` | تصمیم یا قابلیت آینده است و نباید به‌عنوان قابلیت فعال معرفی شود. |
| `Deprecated` | برای سازگاری/تاریخچه باقی مانده و نباید مبنای توسعه جدید باشد. |
| `Unknown` | پاسخ قطعی در مخزن وجود ندارد. |
| `Conflict` | میان کد، تست، پیکربندی یا اسناد تعارض وجود دارد. |

## منابع حقیقت

`Verified` — ترتیب اعتبار: رفتار اجراشده و تست، کد فعال، schema/config، CI/script، سپس این مجموعه سند. فایل‌های قدیمی زیر `docs/architecture`، `docs/current-system`، `docs/engineering` و اسناد دامنه‌ای حذف نشده‌اند و برای بازیابی دانش تاریخی مفیدند، اما هر ادعای Server/PostgreSQL در آن‌ها برای محصول فعلی `Deprecated` و در صورت معرفی به‌عنوان وضعیت جاری `Conflict` محسوب می‌شود.

## هشدار امنیتی

`Verified` — در اسناد جدید هیچ رمز، Token، Cookie، مقدار واقعی env یا داده شخصی ثبت نشده است. اطلاعات پذیرش محلی deterministic در کد seed وجود دارد و نباید به محیط واقعی منتقل شود.
