# واژه‌نامه پروژه

> Status: CURRENT
> Source of truth: این سند برای معنای واژه‌های مشترک محصول و مستندات است.
> Owner: Documentation Architecture
> Last validated: 2026-08-11 against `stable@cea6514`
> Supersedes: none
> Superseded by: none

این واژه‌نامه معنی اصطلاحات را یکسان می‌کند و جایگزین قواعد دامنه یا تعریف دقیق typeها نیست.

| اصطلاح | معنی در Tapra2 |
|---|---|
| Authority / Source of truth | تنها سند رسمی یک موضوع که سایر اسناد باید به آن لینک دهند. |
| CURRENT | رفتار پیاده‌سازی‌شده و بررسی‌شده با repository فعلی. |
| APPROVED-FUTURE | طراحی پذیرفته‌شده‌ای که هنوز رفتار اجرایی نیست. |
| DRAFT | طراحی یا پرسش باز که ممکن است تغییر کند. |
| HISTORICAL | سابقه تصمیم یا وضعیت گذشته؛ دستور اجرای فعلی نیست. |
| Payment Request | درخواست پرداخت خروجی سازمان که در زنجیره خزانه‌داری حرکت می‌کند. |
| Approval Chain | ترتیب کاربران تأییدکننده برای درخواست مالی؛ با سلسله‌مراتب فروش متفاوت است. |
| Allowed Approver IDs | مقصدهایی که مسئول فعلی مجاز است درخواست مالی را به آن‌ها ارجاع دهد. |
| Dual Role | کاربری که هم درخواست‌کننده‌مانند و هم تأییدکننده‌مانند است؛ مقدار `isDualRole` هنگام ذخیره از نقش‌های فعال derive می‌شود. |
| Senior Treasury Supervisor | تنها مقصد ویژه درخواست شخصی کاربر Dual Role؛ با مدیر فروش ارتباطی ندارد. |
| Batch Request | درخواست مالی دارای چند `batchItems` که هر ردیف می‌تواند جداگانه تعیین تکلیف شود. |
| Cost Center | مرکز هزینه/شعبه مرتبط با بودجه و دسترسی درخواست مالی. |
| Support Case | پرونده خدمات پس از فروش، شکایت یا عودت مشتری. |
| Support Transaction Row | ردیف مالی داخل Support Case که چرخه تأیید و ارسال به خزانه دارد. |
| Customer | پروفایل فعلی مشتری فروش با تاریخچه چرخه‌های فروش در `activityLog`. |
| Sale Cycle | یک بازه فعالیت فروشنده روی مشتری با وضعیت `active` یا `completed`. |
| Sales Hierarchy | زنجیره مستقل فروش بر پایه `salesSupervisorId`؛ نباید با Approval Chain ترکیب شود. |
| Lead | فرصت/سرنخ فروش در طراحی آینده؛ در مدل اجرایی فعلی موجودیت مستقلی ندارد. |
| Promotion | زمینه یا پیشنهاد آغاز مکالمه فروش در طراحی آینده؛ بسته ثابت فاکتور نیست. |
| Consignment Inventory | موجودی امانی نماینده در طراحی آینده لجستیک. |
| Persistence | نگهداری داده در مرورگر با `localStorage` در وضعیت فعلی. |
| API Contract | قرارداد پیشنهادی ارتباط client و backend؛ اکنون فقط DRAFT است. |
